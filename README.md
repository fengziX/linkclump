# Linkclump（MV3 中文版）

框选批量打开、复制或收藏多个链接的 Chrome 扩展。基于 [benblack86/linkclump](https://github.com/benblack86/linkclump) 的 fork，已迁移到 Manifest V3、界面汉化，并修复 Chrome 136+ 起「批量打开后标题不变色」的问题。

## 功能

- 按住 `Z` + 鼠标左键拖出选框，松开即批量处理框内链接（默认在新标签页打开）。
- 选项页可添加多组「鼠标键 + 按键 + 动作」：新窗口、新标签页、加入书签、复制到剪贴板。
- 高级选项：智能选择、关键词过滤、打开间隔、自动关闭标签、去除重复链接、倒序打开、标签位置、不聚焦新窗口、站点黑名单。
- **已访问链接标记**：Chrome 136 起 `:visited` 历史按「链接 URL + 顶级站点 + 框架源」分区，扩展从后台打开的链接不会被原页面记为已访问，标题文字不会变色。本扩展自行记录已打开 URL 并给链接染色，颜色自动匹配站点、可手填或关闭、支持清除记录。

> 标记默认只处理**当前视口附近最多 40 个链接**并分批进行，iframe 内不自动标记，也不监听页面 DOM 变动（「自动标记新加载的链接」默认关闭）：给链接加 class 属于 attribute mutation，页面上的重度脚本（如 Bilibili-Evolved 的全局观察器）会为每条 mutation 付出代价，保持小批量对大家都好。需要更激进的恢复时可在选项页打开该开关。

## 安装

要求 Chrome 120 及以上。

1. 克隆本仓库或下载源码。
2. 打开 `chrome://extensions`，开启右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择仓库中的 `src/` 目录（`manifest.json` 所在目录）。

> Chrome 137+ 官方版已忽略 `--load-extension` 命令行参数，不能再用命令行侧载。
> 本地 `file://` 页面还需在扩展详情页勾选「允许访问文件网址」。

## 使用

| 操作 | 结果 |
| --- | --- |
| `Z` + 鼠标左键拖框 | 按默认动作处理框内链接 |
| 选项页 → 动作列表 | 修改或新增触发组合、动作与高级选项 |
| 选项页 → 已访问链接标记 | 开关染色、填写颜色（如 `#8E8E8E`）、清除记录 |
| 选项页 → 站点黑名单 | 逐行填写网址，支持正则 |

设置保存在 `chrome.storage.local`；旧 MV2 版的 `localStorage` 设置不会自动迁移，首次使用为默认配置。

## 打包

扩展根目录就是 `src/`，无需构建步骤。把 `src/` 内的所有文件打成 zip（`manifest.json` 必须在压缩包根目录）即可分发：

```bash
cd src && zip -r ../Linkclump-MV3-zh-CN.zip .
```

## 已知限制

- 已访问标记是扩展自己加的 class，不是浏览器原生 `:visited` 状态；清除浏览器历史不会清除本扩展的记录，请用选项页的「清除已访问标记」。
- 只有「新标签页 / 新窗口」动作会标记；复制、加书签不算访问。
- 站点样式表跨域且无 CORS 时无法自动取色，回退 Chrome 默认紫 `#551A8B`，可在选项页手填。
- 延时打开 / 自动关闭的待办队列存于会话级存储，浏览器进程重启后不再续跑。
- 与 Bilibili-Evolved 同时使用：B-E 在 `document.body` 上挂了 `childList+subtree+attributes+characterData` 的全局 `MutationObserver`（`allMutations`），每个 class 变化都会触发它的全部订阅者。本扩展的标记量已限制在视口内 40 个并分批、iframe 不参与；「自动标记新加载的链接」建议在 B 站保持关闭。

## 更新记录

- **3.0.2**：修复 3.0.0 / 3.0.1 引入的严重性能缺陷。解析站点 `:visited` 颜色时用的正则 `([^{}]*:visited[^{}]*)\{([^{}]*)\}` 在「不含 `:visited` 的长文本」上会逐字符回溯（O(n²)），B 站几十万字符的内联样式触发后单次解析占住主线程约 60 秒，`load` 事件被拖到 63 秒。改为 `indexOf` 线性扫描后，同一环境实测 `load` 从 **63411 ms** 降到 **684 ms**；颜色检测行为不变。
- **3.0.1**：限制已访问标记数量与频率、iframe 不参与自动标记、颜色检测加缓存。
- **3.0.0**：迁移 Manifest V3、界面汉化、修复 Chrome 150+ 批量打开后标题不变色。
